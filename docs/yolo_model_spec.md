# YOLO 모델 최종 스펙 (배포 모델 기준)

> 측정 환경: `src/vision_pkg/weights/best.pt` (Model 3, Fine-tune 최종본)  
> 입력 해상도: 640×480 (카메라 실제 입력), 추론 imgsz: 640

---

## 모델 기본 스펙

| 항목 | 내용 |
|------|------|
| 아키텍처 | YOLOv8n (nano) |
| 파라미터 수 | 3.01 M |
| 모델 파일 크기 | 6.0 MB |
| 입력 해상도 | 640 × 640 (letterbox) |
| 검출 클래스 | 3개: `cup` / `height` / `hand` |
| 학습 프레임워크 | Ultralytics YOLOv8 |

---

## 추론 속도 (실측)

### GPU 환경 (운용 환경)

| 지표 | 값 |
|------|----|
| 평균 레이턴시 | **8.4 ms** |
| 평균 FPS | **~119 FPS** |
| p95 레이턴시 | 9.2 ms |
| 최고 FPS | 125.7 FPS |

### CPU 환경 (비교)

| 지표 | 값 |
|------|----|
| 평균 레이턴시 | 73.4 ms |
