# ALAS Assets

This folder contains media assets for the `2026_ROKEY_Vision-Regent-Cobot` README.

## Structure

- `images/alas_cover.png` : cover image for the README header
- `images/demo_*_thumbnail.jpg` : static thumbnails for demo cards
- `demo/*.mp4` : original demo videos for GitHub links
- `gifs/*.gif` : lightweight animated previews for inline README sections
